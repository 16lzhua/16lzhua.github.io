我的第一篇博客：用 Hexo + GitHub 搭建个人技术博客

发表于2026-09-26|更新于2026-09-26|随笔
|浏览量:

写在前面

这是我博客的第一篇文章。

我现在大二，计算机科学与技术专业。平时课上课下学了不少概念，但越来越觉得，只看书和听课不够，还需要动手做点东西，很多东西真正自己敲一遍、遇到几个问题，再去查资料解决，才会留下比较深的印象。

所以我希望用这个博客记录接下来的学习过程，也慢慢积累一些自己的东西。

为什么搭建个人博客

搭博客最直接的原因，一是我想加学校的创客空间社团，社团的新生训练营有三个赛道选择，我就选择了个人博客的搭建；二是自己之前也有过这个想法，想给自己留下一个可以长期更新的地方。

大学里会学很多东西，也会做不少作业和项目。如果只是做完就结束，过一段时间其实很容易忘掉。把一些东西重新整理成文章，至少能让自己再思考一遍，也方便以后回来看。

同时我也想练一练自己表达东西的能力。
平时遇到一个问题，知道怎么解决是一回事，能把问题怎么出现、自己是怎么排查的、最后又是怎么解决的讲清楚，是另外一回事。写博客刚好可以逼着自己把这些东西理一遍。

为什么选 Hexo + GitHub Pages

我最后选这套方案，原因其实比较简单。

首先，Hexo 是静态博客，文章直接用 Markdown 写，不需要自己折腾服务器。对于现在的我来说，先把内容写起来比较重要。
其次，GitHub Pages 可以直接把博客部署到公网，搭起来以后也比较方便维护。顺便还能接触一下 Git、GitHub 和网站部署这些东西。

这次搭博客本身其实也算是一次小实践。以前知道 GitHub、Markdown 这些东西，但没有真正把它们放到一个完整的流程里用过。

这次搭建的过程

这次基本就是一边看教程一边自己做。
先把 Node.js、Git 这些环境配好，然后初始化 Hexo，安装 Butterfly 主题，最后再通过 GitHub Pages 把博客部署上线。
整个过程并不算复杂，但刚开始还是遇到了一些没想到的问题。

比如第一次执行 hexo d 的时候，提示：
ERROR Deployer not found: git
后来才发现是还没有安装 hexo-deployer-git。

还有一次修改了 _config.yml，本地已经生效了，但公网的页面还是原来的样子。后来发现只是 GitHub Pages 更新有一点延迟。

另外还有一个很小的情况：一开始没有文章的时候，Hexo 生成出来的 public 目录里只有一些 CSS、JS 和图片，没有首页。新建了一篇 Hello World 之后重新生成，首页才正常出现。

这些问题本身都不算复杂，不过第一次自己搭的时候还是需要花一点时间去排查。对我来说，这也是这次实践里比较有意思的一部分。

现在博客准备拿来干什么

我暂时不准备把博客做得特别杂。
之前其实想过以后也写一些杂谈之类的内容，不过后来觉得这类内容还是放在B站比较合适。博客还是想保留一个比较明确的方向。

目前准备主要写三类内容：

第一类是技术笔记。
主要记录自己正在学的东西，比如 Java相关技术栈、力扣学习笔记，以及以后接触到的其他技术。

第二类是经验和项目记录。
想写一些实际做过的东西，比如课程项目、小练习，或者以后实习过程中遇到的问题和经验。

第三类是个人随笔。
这一部分会少一些，主要写一些阶段性的内容，比如年度总结、学习总结、实习日志之类。

接下来的安排

接下来准备先把博客的基本结构完善好，再慢慢调整页面和样式。

文章也不会强求更新频率，还是以自己真正学过、做过的内容为主。
希望慢慢把一些课程之外的东西也记录下来，包括项目、踩坑、实习和一些阶段性的想法。

最后

第一篇文章就写到这里。这个博客现在还很简陋，但它是一个开始。以后我会尽量让它保持更新，也希望过一段时间回头看时，能清楚看到自己走过的路。

最后，欢迎来到我的个人博客！

—— 2026.9.26
